# 一份给南歌子的生日礼物 · From 听听

在原版「生日星星」基础上制作的独立定制版本。保留电脑版、手机版、麦克风吹蜡烛、粒子烟花、隐藏信件和原有彩蛋，并新增“南歌子的星星”隐藏寄语。此定制版不含照片或卡片翻页环节，摄像头手势只保留张开手掌、握拳。

## 本地运行

需要 Node.js 20.9 或更高版本。

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:3000`。也可以直接访问：

- `http://localhost:3000/desktop`
- `http://localhost:3000/mobile`

## 定制内容

专属信息集中在 `app/gift-config.ts` 中，包括南歌子的称呼、出生日期、生日日期、展示年龄、生日祝福、背景音乐路径和专属隐藏星星寄语。出生日期保留为 1995-10-29，2026 年生日展示为“31岁”，不再将出生年份当作年龄展示。

正式流程：生日首页 → 开启仪式 → 许愿吹蜡烛 → 烟花 → 隐藏信件 → 生日结尾。测试结束后先进入生日首页，开启后倒数结束直接前往蜡烛，不经过卡片或照片环节。

烟花不再按固定秒数强制结束：等全部 10 发烟花绽放、粒子消散后再停留 0.65 秒，进入信件。动画按实际帧间隔推进，页面切到后台时暂停，回来后继续，避免低帧率或切换应用时截断尾部烟花。

仅保留的两种手势：

- 张开手掌：生日首页开启仪式；结尾绽放或收拢烟花。
- 握拳：信封环节打开信件；阅读后松开手再握拳，收下祝福进入结尾。

不使用摄像头时仍可轻触对应按钮。吹灭蜡烛继续使用麦克风，或使用轻触备用按钮。

“南歌子的星星”是正式体验右上方更亮的一颗星，生日首页、蜡烛和结尾均可点击。结尾会显示星星名称和轻提示；点击先扩散一圈光晕，再打开隐藏寄语。烟花和信件阶段暂时收起，避免遮挡正文。打开寄语时手势不会误触发页面切换；右上角 ×、Esc 或点击卡片外都可关闭。

本版本不使用照片。你提供的《半情歌》已转换成标准 MP3，并包含在 `public/music/half-love-song.mp3` 中，配置使用：

```ts
musicUrl: '/music/half-love-song.mp3',
```

音乐会循环播放，常规音量设为 32%，吹蜡烛时降为 8% 以减少收音干扰；点击“全屏进入礼物”时启动，手机和电脑均可通过底部声音按钮暂停或恢复。音乐加载失败不影响其他功能。

手机版信件将标题与信纸分开排布，信纸自动填满可用阅读空间；长文可在信纸内上下滚动，末尾保留“收下这份祝福”按钮。信封的轻触入口不再被底部提示条遮挡。电脑端的原有信件布局不变。

仍可通过链接临时修改姓名、日期、展示年龄和结尾文字：

```text
/?name=南歌子&date=2026-10-29T00:00:00%2B08:00&age=31&message=生日快乐
```

## 构建检查

```bash
pnpm build
pnpm start
```

## 部署到 Vercel

建议创建一个新的 GitHub 仓库，不要覆盖通用版仓库。将整个项目上传后，在 Vercel 中导入这个新仓库。Vercel 会自动识别 Next.js，构建命令使用 `pnpm build`，不需要 API Key。

如需让社交分享卡片使用固定正式域名，可在 Vercel 环境变量中添加：

```text
NEXT_PUBLIC_SITE_URL=https://你的域名
```

## 部署到 GitHub Pages

项目已包含 `.github/workflows/deploy-pages.yml`。上传到 GitHub 后，在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**，随后工作流会自动生成静态页面。

## 浏览器权限

摄像头和麦克风只在当前设备中用于实时识别，不会上传或保存。部分内置浏览器不支持所需能力时，页面会提供触控或按钮兼容模式。
